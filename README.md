# SkillHub

SkillHub is a skill-trading platform designed to connect individuals who want to learn new skills with those who can teach them. The platform fosters a collaborative learning environment where users can exchange expertise without financial barriers. 

## Features
- User Authentication: Secure sign-up and login using JWT authentication.
- Skill Matching: Users can list skills they can teach or want to learn.
- Messaging System: Connect with other users to discuss skill exchanges.
- Learning Management: Track progress and access learning resources.
- Community Engagement: Participate in discussions, reviews, and ratings.
- User Dashboard: Manage your profile, skills, and interactions in one place.

## Target Audience
SkillHub is built for:
- Young professionals looking to upskill.
- Students eager to learn new abilities.
- Freelancers and career changers seeking growth.
- Hobbyists wanting to share and gain knowledge.
